```text

```

發言太快時，伺服器只回覆本人提示，不廣播出去。

### 2. 基本文字過濾

伺服器會過濾部分不適合課堂的字串。這是第一版，後續可以改成學校自訂詞庫。

### 3. chat:notice

新增伺服器訊息：

```text
chat:notice
```

用來提示發言太快或訊息未送出。
