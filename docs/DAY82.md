# Day 82 遊戲內回饋表單（2026-06-27）

專案：蓬萊異聞錄 Online  
主題：建立學生可以填寫的測試回饋表單。

## 完成內容

新增表單欄位：

```text
姓名或代號
班級 / 組別
難度 1-5
卡關點
建議
```

表單特性：

```text
固定置中顯示
送出時暫停遊戲鍵盤操作
送出後回到遊戲畫面
姓名與班級會暫存在本機，下一次填寫較方便
```
