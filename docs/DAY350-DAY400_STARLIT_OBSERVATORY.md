# Day350-Day400 星砂觀測台開發紀錄

專案：Penglai Online  
階段：第五章地圖與任務鏈  
主題：從「沉船書庫」延伸到「星砂觀測台」，建立下一段橫向像素 MMORPG 關卡。

## 階段目標

Day350-Day400 的重點是把遊戲從第四章「沉船書庫」往第五章推進，新增一張可探索地圖、一條任務鏈、一組怪物、一組掉落物與裝備，並補上 smoke test，確保既有路線不會被新內容破壞。

## 已完成內容

- 新增地圖：`starlit-observatory`，中文名稱「星砂觀測台」。
- 新增傳送門：沉船書庫尾端可前往星砂觀測台，星砂觀測台入口可返回沉船書庫。
- 新增 NPC：`observatory-keeper`「觀測員阿曜」。
- 新增互動物件：三座 `observatory-lens` 觀測鏡。
- 新增怪物：`star-moth` 星砂蛾、`lens-sentinel` 星鏡哨兵、`astral-keeper` 星穹守望者。
- 新增掉落物：`star-dust` 星砂粉塵、`lens-core` 星鏡核心、`astral-seal` 星穹封印。
- 新增裝備：`star-sabre` 星砂彎刀、`observer-cloak` 觀測者斗篷。
- 新增任務鏈：星砂蛾清理、星鏡核心收集、觀測鏡校準、星穹守望者討伐、星穹封印回報。
- 新增 Boss 區提示、Boss 狀態條與任務導引來源。
- 新增 client fallback sprites，避免正式素材缺失時怪物空白。
- 新增 `smoke:observatory`，驗證第五章傳送門與任務鎖定。
