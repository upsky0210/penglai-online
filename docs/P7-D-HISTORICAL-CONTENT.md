# P7-D 六關歷史內容化

P7-D 將 P7-A／B／C 的場景底圖延伸為玩家看得見的關卡語彙；它不更動 Map ID、任務 ID、敵人類型、任務目標、獎勵、章節鎖或存檔格式。

| Map ID | 玩家名稱 | 時段 | 學習焦點 |
| --- | --- | --- | --- |
| `fog-harbor-test` | 安平開港埠 | 1860–1870 年代 | 開港後的安平港與府城商業網 |
| `mist-breakwater` | 滬尾新學 | 1872–1884 | 淡水河港、醫療與新式教育交流 |
| `old-harbor-warehouse` | 鹿港商棧 | 1880–1905 | 郊商、貨棧與舊港商業網 |
| `coral-tide-cavern` | 稻江茶市 | 1895–1935 | 大稻埕茶葉整理、裝箱與外銷 |
| `sunken-archive` | 艋舺木料街 | 1910–1945 | 河港、木料交易與木作技藝 |
| `starlit-observatory` | 大嵙崁山產線 | 1920–1955 | 三峽／大溪的茶、樟腦與山產運輸 |

## 呈現規則

- HUD 顯示時段、歷史焦點、史實啟發，以及「異聞為遊戲虛構」的標示。
- NPC、傳送門、互動點、地標與敵人顯示名稱改用關卡對應的地方產業與地景詞彙。
- 程式內既有 ID 保持不變，確保已存的角色進度、任務追蹤、互動完成清單與 smoke 測試相容。
- 不把遊戲中的怪物、異變或角色事件宣稱為史實；真實地名與產業只作教學情境的啟發來源。
