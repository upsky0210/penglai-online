# Day401-Day430 星砂觀測台打磨紀錄

專案：Penglai Online  
階段：第五章 Beta 前體驗修正  
主題：讓星砂觀測台更適合測試，不急著新增第六章。

## 階段目標

Day401-Day430 的目標不是新增大量內容，而是把 Day350-Day400 做出的第五章調整到比較能玩、比較好懂、比較適合學生測試的狀態。重點包含任務提示、回報對象、怪物血量、掉落率與測試檢查。

## 已完成內容

- 將「驅散星砂蛾群」需求從 4 隻調整為 3 隻，降低初進第五章的重複戰鬥量。
- 將「收集星鏡核心」需求從 3 個調整為 2 個，讓流程更快進入觀測鏡校準。
- 略降星砂蛾、星鏡哨兵、星穹守望者血量，讓 Beta 測試更容易完成一輪。
- 略提高星砂彎刀與觀測者斗篷掉落率，方便測試裝備系統。
- 在星砂觀測台入口新增「回報：觀測員阿曜」地標。
- 在星穹核心前新增「先校準三座觀測鏡，再挑戰核心」提示。
- 任務日誌改為顯示「回報：NPC」，減少玩家不知道找誰交任務的問題。
- 新增 `smoke:observatory-balance`，檢查第五章任務鏈、數值與掉落設定。
