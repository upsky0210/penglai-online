# P9-C 學生導引改善

## 新手流程

第一輪遊玩在畫面頂部一次只顯示一個步驟；學生完成實際動作後才切換下一步：

1. A/D 移動。
2. W 跳躍。
3. 靠近 NPC，以 E 對話並接任務。
4. K 普通攻擊。
5. J 成功施放技能。
6. 靠近掉落物，等待伺服器確認自動拾取。
7. 完成目標後回 NPC，以 E 回報；收到完成狀態才結束導引。

完成狀態依存檔碼保存在本機，只控制提示顯示，不修改任何伺服器任務或角色資料。完成後頂部改為精簡的 `H / Q / Z` 操作列。

## 任務與路線提示

- 右側任務追蹤只顯示一個「目前目標」，包含短步驟、完成進度、左右方向與約略距離。
- Q 任務日誌保留全部任務與鎖定原因；鎖定項目會指明需先完成哪個前置任務。
- 跨地圖目標使用六關傳送圖的最短路徑，顯示下一個傳送點。即使學生走到錯誤地圖，也能逐站返回正確區域。
- 靠近傳送點時顯示目的地；若當地委託仍有前置任務，會顯示缺少的任務，但不額外阻擋既有傳送規則。
- Boss 區入口顯示實際未完成的前置任務；不再只給模糊的「建議先完成」文字。

## 卡關提示

- 按 H 取得目前任務提示。
- 可接任務：指出 NPC、方向與距離。
- 進行中：指出目標進度，以及目前地圖內方向或跨地圖下一站。
- 可回報：指出回報 NPC、方向與距離。
- H 只讀客戶端已收到的伺服器任務快照，不呼叫接任務、互動、拾取、傳送或完成 API。
- 返回安全區仍使用 Z 連按兩次，修正舊提示誤寫成 H 的問題。

## 畫面與效能

- 不新增中央常駐面板；導引沿用頂部操作列，任務追蹤留在右上角。
- 所有成功回饋沿用短暫 toast／compact notice，不阻塞移動或戰鬥。
- 不新增世界名牌、粒子、伺服器事件或廣播，因此沿用 P8-G4 的低階與多人預算。

## 驗收清單

- [x] 新手七步依實際動作順序消失，並可跨重整保留。
- [x] 第一次 NPC 對話、戰鬥、技能、拾取與回報都有非阻塞回饋。
- [x] 任務追蹤包含目前目標、進度、方向與距離。
- [x] 跨多張地圖能顯示下一站；走錯地圖可導回正確區域。
- [x] 傳送點顯示目的地與當地委託條件。
- [x] Boss 前顯示實際尚缺條件。
- [x] H 不會代做或改寫任務狀態。
- [x] 任務 ID、前置條件、獎勵、戰鬥數值與伺服器權威不變。
