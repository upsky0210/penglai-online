# Day161-Day165 互動點狀態與防重複進度
專案：蓬萊異聞錄 Online  
日期：2026-06-28

## 階段目標

Day161-Day165 的重點是讓互動點更像正式 MMORPG 任務物件：

- 有狀態。
- 能存檔。
- 不能重複刷進度。
- 有專用測試保護。

## 完成項目

- `QuestSnapshot` 新增 `interactedTargetIds`。
- SQLite `quest_states` 新增 `interacted_target_ids`。
- server 會阻止同一互動點重複增加任務進度。
- client 會顯示互動點狀態標籤。
- 靠近互動點時，提示會顯示目前狀態。
- 新增 `smoke:interactable` 回歸測試。

## 對玩家的改善

- 可以看出哪盞霧堤燈已修好。
- 可以看出潮位尺是否已調查。
- 任務流程更清楚，不容易重複做同一件事。
- 任務資料可存檔，重開遊戲後狀態仍保留。
