# P8-G 場景與戰鬥整體收斂

> 狀態：P8-G1、P8-G2、P8-G3、P8-G4 已於 2026-07-12 完成。

本文件承接原 P8-E／P8-F 複核後的未完成項目。`a07723b` 已完成五類任務互動物件與三職業技能特效，但不代表原始 E／F 清單全部完成。

## 已完成，不重做

- NPC：目前六張地圖使用的十名 NPC 已有正式四格待機素材；缺圖時保留程式圖形回退。
- 任務互動物件：港燈、潮尺、茶棧封印／茶箱、木料帳板、樟腦觀測鏡已有正式素材。
- 戰鬥特效：普通墨色斬擊、劍士刀光、符師靈符、獵人射擊、共用技能命中動畫已接線。
- 怪物受擊：已有短暫閃白與擊退抖動。

## P8-G1：場景小物庫

**已完成。** 新增貨箱、麻袋、茶箱、木材堆、竹篩、帳冊／貨單、茶葉乾燥架及完整樟腦蒸餾儀。六張地圖皆至少配置三類前景物件，僅為視覺層，不改角色行走區、碰撞或任務資料。

補齊可重複配置的木箱、麻袋、茶箱、木材堆、竹篩、帳冊、貨單、茶葉乾燥架及完整樟腦蒸餾儀。每項至少提供一個透明 PNG；高頻物件提供 2–3 個輪廓變體，依六張地圖建立配置表，避免把細節全部烘焙在背景中。

驗收：六張地圖各有至少三類前景小物，角色行走區不被遮住，互動物件與純裝飾物件能從輪廓或光點辨識。

## P8-G2：道路、平台與安全區

**已完成。** 六張地圖已改用場景化街口／碼頭／木橋／山路傳送標記；平台採石板、木棧、屋頂、碼頭、山路五套材質；安全區改成地面光紋、燈火與短標籤，碰撞與傳送資料未變。

- 傳送點：移除目前的圓形加矩形門框，依地圖替換為府城街口、河港碼頭、鹿港棧道、大稻埕茶埠、艋舺木橋、山路關口。
- 平台：將單一 `harbor_platform_tiles` 拆成石板、木棧、屋頂、碼頭及山路五套表面；碰撞矩形保持透明且不改伺服器座標。
- 安全區：移除大面積綠色透明矩形，改用低強度地面光紋、旗幟或成對燈火；名稱保留但降低常駐干擾。

驗收：傳送目的地仍完全相同；平台碰撞、跳躍與怪物巡邏不變；安全區在背景明暗兩端都可辨識。

## P8-G3：戰鬥與介面視覺收斂

**已完成。** 技能命中加入潮霧層，怪物死亡改為暗化、縮退、上浮及霧點消散；NPC、怪物與互動標籤統一為 11 px 固定寬度；怪物加入接觸影與統一名稱描邊，遠端玩家維持金色識別。

- 補齊潮霧類戰鬥特效，統一刀光、墨痕、潮霧與命中特效的色盤、尺寸、深度及同屏上限。
- 保留受擊閃白，新增怪物死亡的短促墨化／霧化消散；目前僅降至 `alpha 0.25`，不算死亡動畫。
- 統一 NPC 名牌、怪物名稱、互動提示的字級、padding、最大寬度與垂直避讓。
- 建立角色／背景明暗分離規則：主角與 NPC 使用輕量暗邊或腳底接觸影；敵人使用一致的敵對輪廓／血條層級；遠端玩家維持金色識別但降低整體染色。

驗收：960×540 與常用放大比例下文字不重疊；亮、暗、霧三種背景位置皆能在一秒內分辨主角、隊友、NPC 與敵人。

## P8-G4：低階效能與多人密度

**已完成。** 遠端玩家、怪物、掉落物與戰鬥特效加入相機外裁切；標籤、特效、遠端音效設有高／低階預算；低階模式停用次要光暈與環境動畫。`npm run check:p8-g` 固定驗證 40 玩家、45 怪物、50 瞬時特效的低階上限。

- 為戰鬥粒子、動畫與名牌建立相機可視範圍判定及同屏數量上限。
- 遠端技能音效沿用節流，新增遠端 VFX 節流；離屏角色停止非必要動畫或降頻。
- 建立低階模式：關閉附加光暈／霧層、降低動畫更新頻率，但不得影響碰撞與任務提示。
- 擴充多人壓力驗證，至少覆蓋密集玩家、怪物、掉落物、名牌及連續技能。

驗收：以既有課堂基準場景比較，不增加伺服器廣播量；低階模式下功能一致，且多人密集畫面沒有無上限建立的 tween、文字或特效物件。

## 建議執行順序

1. G2 平台／傳送點／安全區：最直接消除目前畫面的程式矩形感。
2. G1 場景小物庫：補足背景前景的層次與地方辨識。
3. G3 戰鬥、名牌與輪廓：統一可讀性。
4. G4 效能與多人壓測：在視覺規格穩定後定出正式預算。
