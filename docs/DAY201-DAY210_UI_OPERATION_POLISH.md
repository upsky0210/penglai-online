# Day201-Day210 UI 與操作體驗改善
專案：蓬萊異聞錄 Online  
日期：2026-06-28

## 階段目標

這一階段主要處理試玩時最影響體驗的問題：

- 對話框擋住主角與怪物。
- 技能冷卻提示太大。
- 掉落物需要按 F 才能撿。
- 裝備操作不清楚。
- 按鍵提示不夠明顯。

## 已完成

- Claude Design 素材已放入 `client/public/assets/`。
- 對話框移到畫面上方並縮小。
- 技能冷卻與法力不足改成小型提示。
- 掉落物碰到後自動拾取。
- 背包加入 `1 使用藥水`、`2 裝備武器`、`3 裝備防具`。
- 背包顯示 `[可裝備]`、`[裝備中]`。
- 左上方新增亮白按鍵提示。

## 保留的安全設計

- 自動拾取仍由 server 檢查距離、地圖與角色狀態。
- 裝備仍由 server 檢查物品是否存在、是否為裝備。
- 素材管線仍保留 fallback。
