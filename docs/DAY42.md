# Day 42 教師全服公告（2026-06-26）

專案：蓬萊異聞錄 Online  
階段：課堂控場工具

## 今日目標

讓教師可以從管理頁送出全服公告，所有線上玩家即時收到訊息。

## 完成內容

### 1. 新增公告 API

```text
POST /admin/broadcast?token=ADMIN_TOKEN
```

請求：

```json
{ "text": "公告內容" }
```

成功後透過 WebSocket 廣播：

```text
admin:notice
```

### 2. 前端顯示教師公告

玩家端收到公告後會顯示：

```text
教師公告：公告內容
```
