# 安平單機探索樣板

啟動：`npm install` 後執行 `npm --workspace client run dev`，開啟終端顯示的網址。不需要啟動 server 或設定 Firebase。

預設入口為安平單機版；原有多人版本保留在 `?online=1`，仍需原本的後端。`?admin=1` 仍為舊版管理面板。

## 操作與路線

A/D 移動，W 或空白跳躍，E 互動，K 普攻，J 範圍技能，Q 探索筆記，R 回檢查點，Esc 關閉對話。貨箱查驗使用滑鼠選擇。

1. 與帳房交談接下委託。
2. 從西側木台跳上高架倉棧，取得工具匣與貨單。貨單記錄「帆船」箱記。
3. 找居民阿秀開啟家書支線並更新檢查點。
4. 修橋開通捷徑，或等待低潮沿下方通道前進。潮間藏物包含家書，回交阿秀完成支線。
5. 在東碼頭依貨單查驗貨箱，更新檢查點。
6. 擊退虛構的霧潮守衛，再敲響信號鐘完成主線。可繼續探索未完成的支線。

本機存檔鍵為 `penglai-anping-solo-v1`，與原有多人存檔隔離。自動記錄事件、金幣與檢查點；重開後恢復體力及小怪。清除瀏覽器網站資料會清除進度；目前尚無匯出與匯入介面。

### 第一輪試玩修正

- 行走速度由 235 調整為 211.5 px/s（0.9 倍）；跳躍高度維持原值。
- 木架新增低階踏台，平台只從上方承接角色，可從下方跳穿。
- 潮汐為 36 秒一循環，退潮 24 秒、漲潮 12 秒；對話時暫停。藍色水面會升降，漲潮前 4 秒預警。水面高度也用於實際淹水判定，持續淹水 1.6 秒後救回檢查點。
- 自動記錄沿路檢查點，落水、體力耗盡或手動返回會說明原因及返回位置，保留任務與金幣。
- 敵人顯示名稱與血條；命中顯示傷害數字。普攻使用金色弧形斬擊，技能使用較大的藍色弧形與扇面。

瀏覽器鍵盤測試已驗證 0.9 倍速度、從地面登上高架道、退潮通行與漲潮救援；另驗證任務門檻、支線回交及存檔重載。這些檢查不代表完整真人試玩的手感驗收。

## 範圍與後續

這是可玩的關卡樣板，採用既有主角貼圖與程式繪製的港區灰盒。尚未量產場景美術、NPC 動畫、音效、背包裝備或其他五關；金幣目前作為探索記錄，不具商店用途。潮汐是簡化的遊戲週期，非真實安平潮汐模擬。目標遊玩時間仍需真人試玩測量。

史實背景沿用 `P9-B-HISTORICAL-DEPTH.md` 的安平史料。三名 NPC、貨單事件、家書、機關與敵人均為虛構；不將箱記配對視為歷史知識測驗。

## Pages

既有 GitHub Actions 手動部署流程已移除必填後端網址的檢查。repo Settings → Pages → Source 選 GitHub Actions，再手動執行 Deploy client to GitHub Pages。推送程式不會自動部署，需另外手動執行 workflow。

## 驗證

`npm --workspace client run typecheck`

`npm --workspace client run build`

瀏覽器驗證需涵蓋：任務前置條件、修橋工具、貨箱選擇、守衛門檻、家書回交、存檔重載、平台碰撞及主線完成。路線手感與時間分配仍需真人走圖調整。
