# P7 歷史場景與美術 Bible（1860–1955）

## 定位

《蓬萊異聞錄 Online》的六關改以「開港通商至戰後初期的臺灣地方記憶」為歷史底層，保留潮、霧、星造成的誌異現象。場景是受史實啟發的虛構蓬萊，不宣稱為一比一古蹟復原；真實年代、人物與制度放入可查證的地方誌卡片。

核心視覺語句：**港、河、山串起臺灣與世界；庶民勞動維持每一條產業線。**

## 共用製作規格

- 遊戲畫布：960×540；背景來源以高解析橫幅構圖製作，接入時完整覆蓋畫布高度。
- 風格：高密度像素插畫／pixel-painted environment，輪廓清楚、材質豐富，不使用照片、3D、油畫筆觸或可辨識的既有遊戲風格。
- 深度：每關至少包含天空／天花、遠景地貌、聚落輪廓、主建築、遊戲平面、前景遮擋、氣氛特效七個視覺深度；第一批生成資產作為高密度 backplate，程式地標、平台、霧與互動物件提供其餘深度。
- 構圖：底部 35% 保留可讀的橫向遊戲平面；主要地標放在中上景，不遮住 HUD、角色、NPC 名牌與任務提示。
- 光色：一關一組主光色、一組異象色。異象固定使用低比例青藍／紫光，避免全畫面到處發光。
- 像素：使用有限色盤、明確 cluster、選擇性描邊與克制抖色；不能把寫實圖片單純套 pixel filter。
- 歷史物件：不混入超出該關年代的汽車、招牌、路燈、電器、建材與服裝。
- 人物：主線 NPC 使用虛構合成人物；史實人物只出現在地方誌，不把殖民官員或傳教士塑造成單一救世主／反派。
- 觀點：每關至少出現管理者／商人、勞動者、居民三種視角；日治場景同時呈現建設、產業、制度控制與戰爭影響。

## 六關時間軸

### 第一章：霧港開埠

- Map ID：`fog-harbor-test`
- 史實原型：臺南府城／安平港
- 年代：1860–1870年代
- 色盤：夕陽砂金、府城灰磚、糖袋米白、港水青灰；異象為淡紫雷紋。
- 地標：府城牆影、安平港口、海關旗杆、洋行倉棧、帆船桅杆。
- 材質：蚵殼灰、紅磚、老木、麻繩、石板、糖包。
- 互動：貨物查驗、修復碼頭、辨認糖與洋貨、重整海關封條。
- 禁用：完整現代柏油路、汽車、霓虹字、鋼筋混凝土港廈。

### 第二章：滬尾新學

- Map ID：`mist-breakwater`
- 史實原型：淡水滬尾、傳教醫療與牛津學堂
- 年代：1872–1884
- 色盤：河霧藍灰、清水紅磚、閩南黑瓦、榕樹綠；異象為冷青醫療燈。
- 地標：河港斜坡、紅磚學堂、偕醫館意象、鐘樓、洋商館與觀音山。
- 材質：紅磚、黑瓦、石灰牆、木百葉、藥草與印刷紙張。
- 互動：整理藥材、修復學堂、台語／外語對照、自然科學標本。
- 敘事護欄：同時呈現醫療教育、文化交流、地方疑慮與衝突。

### 第三章：鹿港商棧

- Map ID：`old-harbor-warehouse`
- 史實原型：鹿港郊商與舊港貿易網
- 年代：1880–1905
- 色盤：赭紅磚、靛藍布、香火金、潮濕木褐；異象為銅綠帳紋。
- 地標：不見天街、長條街屋、郊商會館、狹窄碼頭與淤積水道。
- 材質：穿斗木構、磚牆、布匹、藥材箱、石材與木材。
- 互動：核對商號帳冊、安排貨物轉運、疏通水道、修復行郊標記。
- 敘事護欄：本章呈現老商港延續與轉型，不把 1880 年後畫成鹿港最鼎盛的單一時刻。

### 第四章：稻江茶市

- Map ID：`coral-tide-cavern`
- 史實原型：大稻埕茶葉加工、河運與外銷
- 年代：1895–1935
- 色盤：茶褐、洋樓赭紅、河面金、包裝紙米白；異象為墨綠茶霧。
- 地標：淡水河碼頭、茶行洋樓、揀茶場、烘茶煙囪、出口木箱。
- 材質：茶葉、竹篩、木箱、鉛字標籤、紅磚拱窗、磨石地面。
- 互動：揀茶、烘茶、裝箱、秤重、辨認外銷商標。
- 人物：揀茶女、碼頭工、茶行夥計、外銷商與街區居民。

### 第五章：艋舺木料街

- Map ID：`sunken-archive`
- 史實原型：艋舺河港、剝皮寮、木材加工與廟宇大木作
- 年代：1910–1945
- 色盤：杉木黃褐、廟埕朱紅、煤煙灰、戰時暗綠；異象為灰藍木紋裂光。
- 地標：剝皮寮街屋、木料堆、鋸木工坊、龍山寺屋脊意象、萬華木造驛站。
- 材質：杉木皮、刨花、榫卯、廟瓦、舊鐵軌、沙包與受損磚牆。
- 互動：量木、剝皮、辨識榫卯、修復木構件、保存戰時帳冊。
- 史實護欄：「剝皮寮因杉木剝皮得名」標為地方說法之一，不當作唯一確定解釋。

### 第六章：大嵙崁山產線

- Map ID：`starlit-observatory`
- 史實原型：三峽／大溪茶葉、樟腦、山林運輸與戰後復工
- 年代：1920–1955
- 色盤：茶園深綠、樟木暖褐、紅磚街屋、蒸氣銀白；異象為星砂金與樟腦青焰。
- 地標：山城河階、茶園、樟腦寮、製茶工場、輕便軌道與大漢溪。
- 材質：茶簍、蒸餾桶、木軌枕、紅磚山牆、竹管與白煙。
- 互動：採茶、製茶、控制蒸餾、修復輕便軌道、重新串接港河山運輸。
- 敘事護欄：呈現山林產業的收入與環境代價，終章不是單純歌頌資源開採。

## 產業主線

玩家修復六冊被潮霧打亂的地方誌：安平讓島嶼重新與世界通商；滬尾帶來跨文化醫療與新學；鹿港保存舊商業網；大稻埕把北臺灣茶葉送往海外；艋舺承接河港與木作；三峽／大溪揭示茶與樟腦如何從山區沿河運往稻江與淡水。

## 驗收

- 隱藏 UI 後，只看截圖仍能分辨六個場景與大致年代。
- 每關至少有一個大型地標、三種主要材質、十二個生活／產業小物件。
- 角色與敵人相對背景有清楚明度或色相差，不被高密度細節吞沒。
- 背景可水平循環或在地標段落自然重複，沒有明顯接縫與文字亂碼。
- 960×540 遊戲畫面中，平台、NPC、傳送門、互動提示與 HUD 仍可讀。
- 所有史實卡片必須記錄來源；AI 生成圖不得出現可辨識商標、現代物件、亂碼招牌或錯誤國旗。
