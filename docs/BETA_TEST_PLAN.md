# P9-E 試教版測試計畫

## 測試目標

```text
六關學生流程可完整遊玩
多人連線基本穩定
教師能查看進度、發送提示並安全處理位置問題
學生回饋可收集與匯出
資料可備份與還原
```

## 測試角色

```text
老師：管理面板、課堂提示、安全區重置、備份、課堂成果 CSV 匯出
學生：完成新手流程與至少一關、使用卡關提示、填寫回饋
觀察者：記錄卡關點、操作困難、畫面可讀性
```

## 測試梯次

```text
第 1 梯：老師自測 1 人
第 2 梯：小組測試 3-5 人
第 3 梯：半班測試 10-15 人
第 4 梯：完整班級測試
```

## 每梯必做

```text
開始前建立備份
測試中觀察 server 是否斷線
測試後下載回饋 CSV
測試後下載課堂成果 CSV
測試後建立備份
記錄 bug 與下次修正優先順序
```

## 通過標準

```text
新玩家不看外部說明可完成首次對話、戰鬥、拾取與任務回報
六關前置條件、跨關傳送、存檔與重連回歸通過
無整班斷線
管理面板可看到任務進度與保守的需關注原因
安全區重置不清除任務、等級、道具或存檔
回饋與課堂成果資料可匯出，且不含 token、session 或不必要個資
1366×768 與 1920×1080 的 HUD、對話、提示及世界文字不重疊
資料庫備份成功
```

詳細驗收矩陣、試教前檢查表、已知問題及 30～45 分鐘流程，見 `docs/P9-E-TRIAL-RELEASE.md`。
