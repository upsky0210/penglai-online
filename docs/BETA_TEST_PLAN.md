# Beta v0.1 測試計畫

## 測試目標

```text
第一章可完整遊玩
多人連線基本穩定
教師管理可控場
學生回饋可收集與匯出
資料可備份與還原
```

## 測試角色

```text
老師：管理面板、公告、聊天控場、備份、CSV 匯出
學生：遊玩第一章、聊天、回饋表單
觀察者：記錄卡關點、操作困難、畫面可讀性
```

## 測試梯次

```text
第 1 梯：老師自測 1 人
第 2 梯：小組測試 3-5 人
第 3 梯：半班測試 10-15 人
第 4 梯：完整班級測試
```

## 每梯必做

```text
開始前建立備份
測試中觀察 server 是否斷線
測試後下載回饋 CSV
測試後建立備份
記錄 bug 與下次修正優先順序
```

## 通過標準

```text
80% 學生可完成第一章
無整班斷線
管理面板可看到線上玩家
回饋資料可匯出
資料庫備份成功
```
