# P8-C / P8-D NPC 與怪物美術交付

## P8-C NPC

六張歷史地圖現在共用同一套 80×80、四格待機規格。除安平港吏外，新增林藥師、陳商人、燈塔學徒、防波堤斥候、余潮汐研究員、倉庫管理人、洞窟學者、檔案館長與觀測所管理人。服裝與道具依場景分別使用藥秤、算盤、潮汐筆記、倉庫鑰匙、茶盤、木工量尺及樟腦壓力計。

## P8-D 怪物

十五種怪物均有獨立四格待機動畫。小怪使用 64–96 px 格框，關主使用 128×96 格框；程式仍以既有戰鬥碰撞與顯示尺寸為準，因此本次只替換視覺，不改戰鬥平衡。

- 安平／淡水：糧倉鼠、霧泥、潮汐守望者
- 鹿港：貨倉鼠、霧偶、倉庫哨兵
- 大稻埕：茶殼蟹、茶霧靈、茶棧守衛
- 艋舺：檔案漂流者、墨靈、木作檔案守衛
- 三峽／大溪：星紋茶蛾、樟腦鏡哨、茶樟星象守護者

## 資產規則

- 最終 PNG 位於 `client/public/assets/p8/npcs` 與 `client/public/assets/p8/monsters`。
- 來源生成圖保留在被 Git 忽略的 `tmp/imagegen/p8`；`scripts/build-p8-sprites.py` 負責縮圖、對齊與透明角落檢查。
- `assetManifest.ts` 是唯一載入表；若外部圖片缺失，遊戲仍會回退到原本的程式圖形。
- 圖像為本專案原創角色設計，只沿用 1990 年代台灣單機 RPG 的可讀性、手繪像素密度與暖色歷史質感，不複製既有角色。
