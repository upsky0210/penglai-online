# Day431-Day460 Beta 測試回饋系統

專案：Penglai Online  
階段：Beta 測試準備  
主題：讓學生回饋更完整，讓老師更容易整理測試結果。

## 階段目標

Day431-Day460 不再新增地圖，而是把現有五章內容接到 Beta 測試流程。重點是讓學生能清楚回報問題，老師能從管理端快速看到班級、地圖、問題分類與難度狀況。

## 已完成內容

- 回饋表單新增「學校」欄位，可用於正式測試或不同學校場次。
- 回饋表單新增「回饋分類」：Bug、任務路線、難度平衡、介面文字、卡頓連線、新增內容、其他。
- 回饋表單新增「測試裝置」：桌機、筆電、平板、手機、不確定。
- 回饋表單新增「老師可以再詢問我」勾選欄位。
- 回饋送出時自動記錄目前地圖、目前區域、目前導引任務與章節進度。
- SQLite `test_feedback` 新增相容欄位，舊資料不會被清掉。
- `/admin/summary` 新增 `betaFeedback` 統計：
  - 回饋總數
  - 待處理回饋數
  - 平均難度
  - 依班級統計
  - 依地圖統計
  - 依分類統計
  - 最近待處理回饋
- 管理面板回饋列表新增顯示學校、分類、裝置、可否追問、地圖區域、目前任務。
- CSV 匯出新增完整 Beta 回饋欄位。
- smoke 測試新增新欄位送出與 admin summary 統計檢查。

## Padlet AI 日誌簡記

今天把遊戲往 Beta 測試版本推進。原本學生只能填姓名、班級、卡關點與建議，現在可以補學校、問題分類、裝置類型，也會自動記錄目前地圖、區域與任務。老師端的 summary 也新增回饋統計，之後看整班測試結果會比較有效率。
