# Day 21 開發紀錄
日期：2026-06-25  
專案：蓬萊異聞錄 Online  
主題：區域導覽與任務方向提示

## 今日目標

Day 18 到 Day 20 已完成右側新地圖、新怪物、新任務與設定面板。  
Day 21 作為暫時收工前的整理，目標是讓玩家比較知道自己在哪裡、該往哪裡走。

## 完成內容

### 1. 區域名稱提示

新增畫面上方的區域提示 banner。  
玩家進入不同區域時會短暫顯示區域名稱。

目前區域：

```text
霧港郊外
潮汐林道
潮汐林道深處
安全區
燈塔營地
```

安全區名稱直接使用地圖資料中的 safe zone。

### 2. 地圖路標

在世界場景中新增路標：

```text
往右：燈塔營地
往右：潮汐林道
注意：海霧史萊姆
```

這些路標是地圖物件，不是 HUD，玩家往右走時會在場景內看到。

### 3. 任務方向提示

任務追蹤面板新增方向提示。

範例：

```text
往右 320
往左 180
附近
```

邏輯：

```text
可接任務 -> 指向 NPC
可回報任務 -> 指向 NPC
擊殺任務 -> 指向目標怪物出生區
收集田鼠尾巴 -> 指向田鼠區
收集海霧凝膠 -> 指向海霧史萊姆區
```

這一版先用水平距離提示，不做完整小地圖。
