# P9-A2 試玩問題修正

來源：2026-07-12 安平關卡實際試玩截圖與使用者回饋。

## 問題摘要與優先順序

### P0：Smoke test 公告污染正式遊玩資料

現象：公告面板顯示 `Smoke test announcement`，且中央大型面板遮住主要遊戲畫面。這不是 NPC 對話；`scripts/smoke.mjs` 會呼叫公告 API 建立測試公告。若 smoke 指向一般開發資料庫，測試資料會保留到玩家端。

修正範圍：

- smoke 一律使用隔離資料庫，或在測試結束時可靠刪除它建立的公告。
- 測試公告使用唯一前綴與短 TTL，並增加「一般資料庫不得存在 smoke 公告」檢查。
- 玩家端公告預設維持收合；新公告只顯示不擋畫面的短提示，不自動展開中央面板。
- 公告面板增加明確關閉提示，並限制高度、文字行數與捲動方式。
- 提供一次性的既有 smoke 公告清理方式，但不得誤刪老師發布的公告。

驗收：執行 `smoke`、`check:beta`、`check:release` 後，以一般存檔登入看不到任何 smoke 字樣；公告到達時不遮住角色及戰鬥區。

### P1：掉落道具正式圖示

現況：`RemoteEntityLayer.getOrCreateItemDrop()` 使用 24×18 朱紅矩形加亮點，與 P8 美術落差明顯。

修正範圍：

- 依物品類型建立小型掉落圖示：藥水／便當、怪物素材、任務關鍵物、武器、防具。
- 優先為目前實際會掉落的素材建立獨立圖示；無專用圖時使用類型 fallback，不再使用紅色矩形。
- 圖示維持底部中心定位，加入低強度光點與拾取距離回饋。
- 名稱與數量改成固定寬度小標籤；密集掉落時沿用 P8-G4 名牌預算。

驗收：六關所有掉落物都有可辨認圖示；同時出現多個掉落物時不遮住怪物血條與角色。

### P1：文字清晰度與排版

現象：中文筆畫偏糊、部分文字顯得像低解析度放大。現在 Phaser 設為 `pixelArt: true`，遊戲又以 FIT 縮放，這對點陣圖片有利，但不一定適合系統中文字體。

修正範圍：

- 實測 Canvas 實際解析度、devicePixelRatio 與 FIT 縮放比例。
- 圖片保留 nearest／pixel-art；UI 文字改用適合中文字型的高解析度渲染策略，避免文字跟著低解析 Canvas 放大。
- 統一 HUD、公告、任務、名牌的字級、行高、描邊與背景透明度。
- 優先使用正體中文字體堆疊，確認 Windows 實機不落到低品質 fallback。
- 960×540、1920×1080 與瀏覽器 125% 縮放各做一次截圖比較。

驗收：常用解析度下「霧港旅人、任務、生命、法力」筆畫清楚；文字不溢出、不重疊，背景圖片仍保持點陣質感。

### P1：升級動畫與生命／法力同步

現況：伺服器升級時已有 `hp: player.maxHp`、`mp: player.maxMp`，客戶端也有單行「升到 N 級」文字動畫；仍需確認升級事件與下一次 snapshot 的 HUD 同步順序。

修正範圍：

- 升級增加角色周圍光環、上升光點與短促音效；低階模式使用簡化版本。
- 升級時由伺服器補滿 HP／MP，立即送出包含完整新狀態的 snapshot 或等價權威更新。
- 客戶端收到升級事件後不得自行猜數值；HUD 以伺服器狀態更新。
- 增加回歸測試：殘血、缺 MP 狀態升級後，HP 與 MP 都等於最大值，存檔後重連仍正確。

驗收：殘血升級瞬間可看到動畫，血條與法力條補滿；重登後數值一致，不發生先補滿又跳回舊值。

## 建議執行順序

1. A2-1：隔離／清理 smoke 公告，修正公告遮擋。
2. A2-2：正式掉落物圖示與類型 fallback。
3. A2-3：文字渲染解析度與 UI 排版。
4. A2-4：升級動畫、權威狀態同步與回歸測試。
5. 執行六關試玩、`check:p8-g` 與完整 `check:release`。
