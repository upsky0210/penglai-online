# P9-B 歷史內容深化

## 教學目標

六關以「地點、年代、產業、對外連結」為共同框架。史實不集中在長篇面板，而分散到 NPC 接任務短句、任務完成回顧、互動物件與右側導覽。潮霧、怪物、封印、核心及守望者均明確視為遊戲虛構。

## 六關內容矩陣

| 關卡 | 年代與地點 | 3–5 個學習重點 | 完成後可回答 |
| --- | --- | --- | --- |
| 安平開港埠 | 1860–1870 年代，臺灣府城／安平 | 開港設關、洋行與倉棧、府城支援港區、貨物進出口 | 靠港口貿易與倉儲發展；以海關、洋行、航運連接海外。 |
| 滬尾新學 | 1872–1884，滬尾／淡水河口 | 1872 傳教接觸、1880 偕醫館、1882 理學堂大書院、潮位測量與航標 | 靠河港運輸並發展醫療教育；由河口交換人員、知識與貨物。 |
| 鹿港商棧 | 1880–1905，鹿港 | 郊商同業組織、信用與調解、貨棧轉運、淤積與交通轉型 | 靠郊商與貨棧貿易；以商號及船運網絡連結福建與臺灣各地。 |
| 稻江茶市 | 1895–1935，大稻埕 | 丘陵茶菁、揀茶烘焙分級、茶箱包裝、淡水河外銷、女性與碼頭勞動 | 靠茶葉精製與外銷；由淡水河接到淡水港與海外。 |
| 艋舺木料街 | 1910–1945，艋舺 | 河港型市街、木料運入、製材與榫卯分工、交通改變城市重心 | 靠木料交易、貨運與木作；河運連結山林材料與城市需求。 |
| 大嵙崁山產線 | 1920–1955，三峽／大溪 | 茶與樟腦、蒸餾工序、1903 後輕便鐵道、日治制度管理、1945 後復工與環境代價 | 靠茶、樟腦與山產加工；由河運、輕便鐵道及縱貫鐵路連到外部市場。 |

## 時序與虛實護欄

- 安平、淡水與鹿港以清治後期為主；大稻埕跨清末產業基礎與日治時期延續，但遊戲段落聚焦 1895–1935。
- 艋舺聚焦 1910–1945，不放入戰後現代建設。
- 三峽／大溪先呈現 1920 年代山產與日治管理；最後一項任務才明說「時間推進到 1945 年後」。
- 虛構敵人只作玩法目標。任務短句會直接說明哪些元素是「遊戲異聞」。
- 「剝皮寮因剝木皮得名」缺乏單一確證，本次正式文案不採用此說作結論。
