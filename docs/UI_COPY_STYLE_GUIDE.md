# UI 文案風格指南

專案：蓬萊異聞錄 Online  
日期：2026-06-28

## 語言原則

- 使用台灣正體中文。
- 按鈕文字短而明確。
- 面板標題以 2 到 6 個字為主。
- 系統提示要直接說明下一步。
- 教師後台文字偏操作導向，不使用遊戲劇情語氣。
- 玩家端文字可以保留世界觀語氣，但不能影響理解。

## 固定詞彙

```text
任務
背包
角色
地圖 / 流程
公告
回饋
後台
安全區
金幣
經驗
生命
法力
```

## 避免用語

```text
不要使用簡體中文
不要混用英文縮寫，除非是按鍵或技術名詞
不要讓提示文字超過面板寬度
不要在遊戲內寫太多操作說明
```

## 後台文案

後台是給老師或管理者使用，應該清楚、短句、可掃讀。

建議：

```text
送出公告
下載公告 CSV
回饋狀態已更新
已鎖定全班聊天
資料庫備份已建立
```

## 玩家端文案

玩家端要簡短，優先說明目前能做什麼。

建議：

```text
任務已接受
任務可回報
拾取物品
已返回安全區
前方為潮眼守衛區
```
