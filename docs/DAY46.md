# Day 46 單人禁言控場（2026-06-26）

專案：蓬萊異聞錄 Online  
階段：課堂控場第二階段

## 今日目標

讓教師可以針對單一線上玩家暫時禁言，不影響角色移動與遊戲進度。

## 完成內容

### 1. 新增禁言 API

```text
POST /admin/mute?token=ADMIN_TOKEN
```

請求：

```json
{
  "playerId": "線上玩家 ID",
  "muted": true,
  "reason": "教師已暫時限制你的聊天。"
}
```

### 2. 管理頁操作

線上玩家卡片新增：

```text
禁言
解除禁言
```

### 3. 玩家提示

被禁言玩家嘗試發言時，只會收到本人提示，不會廣播訊息。
