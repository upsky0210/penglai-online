## 學生端與教師功能聯動

- 全班公告與個別提示不得展開中央大型面板。
- 老師重置位置只回目前地圖安全區，不改任務、等級、道具或存檔。
- 未授權管理員 API 必須拒絕；成功操作必須留下 action log。
- 成果 CSV 不含 email、save slot、password、token 或 session。

## 解析度與文字

- 1366×768：檢查頂部新手提示、左側 HUD、右側任務追蹤、底部 prompt 與世界名牌。
- 1920×1080：檢查 Canvas FIT 後中文字筆畫、對話框與公告 toast。
- 兩種目標解析度皆使用 960×540 內部座標；1366×768 為 1.422 倍 FIT，1920×1080 為精確 2 倍，P9-E 自動檢查會阻止比例與標題間距退化。
- 世界路牌木板固定在 terrain／prop 上方，文字固定在角色與場景物件上方。
- 對話與提示不得遮住角色所在的畫面中央。

## 資料潔淨

- 正式學生 runtime 不得含 Smoke 公告、Smoke 角色、Lorem ipsum 或假資料文案。
- release 使用隔離 SQLite；smoke 公告帶唯一前綴並於結束前清除。
- `.claude/` 保持未追蹤，不納入封版 commit。

## 已知問題

- 前端 production bundle 仍會出現 Phaser 主 bundle 大於 500kB 的既有警告；不影響本機課堂載入與 40 人伺服器負載，但跨網路首次下載需預留時間。
- 卡關判定是保守提示，不代表學生一定卡住；老師仍需先查看任務與活動原因。
- 管理權限目前是單一 `ADMIN_TOKEN`，尚未分級；管理網址與 token 不可提供給學生。

## 封版測試結果

- `check:release`：20 個隔離資料庫階段全數通過。
- 40 人課堂負載：13.2 Hz；tick 平均／最大 4.36／8.27 ms；教師列表 19.29 ms。
- 40 人存檔：40 次嘗試、0 失敗、0 排隊；平均／最大 1.41／1.91 ms。
- 廣播預算：同地圖資料每輪只序列化一次，序列化成本不隨玩家數線性增加。
- production build：通過；保留上述 Phaser bundle 大小警告作為已知問題。

## 30～45 分鐘教師試教腳本

| 時間 | 老師操作 | 學生活動 | 觀察重點 |
|---|---|---|---|
| 0–5 分 | 開啟後台、確認人數；說明虛構異聞與真實歷史的區別 | 建立角色、完成 A/D/W/E | 是否能自行找到第一位 NPC |
| 5–12 分 | 發全班提示：「完成安平第一個委託，留意港口如何連外」 | K/J 戰鬥、自動拾取、回報 | 新手步驟是否依完成動作消失 |
| 12–20 分 | 查看任務進度；對落後學生發方向提示 | 完成安平任務並前往滬尾 | 提示是否不遮擋中央、不代做任務 |
| 20–28 分 | 引導比較安平港貿易與滬尾醫療教育 | 與 NPC／互動物件取得短史實 | 能否回答產業及對外連結 |
| 28–35 分 | 示範需關注原因；必要時將一名學生送回安全區 | 測試 H 卡關提示、Z 自助返回 | 重置後任務、等級與道具是否保留 |
| 35–40 分 | 請學生按 T 回饋；匯出課堂成果 CSV | 回答兩題學習回顧並送回饋 | CSV 欄位是否適合課堂整理 |
| 40–45 分 | 說明後續四關；建立課後備份 | 分享一個地點的產業與連外方式 | 無整班斷線、資料完整保存 |

30 分鐘版本可在第 28 分鐘直接進入回顧與回饋；45 分鐘版本保留安全重置示範及全班分享。
