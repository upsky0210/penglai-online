# Day 16 開發紀錄
日期：2026-06-25  
專案：蓬萊異聞錄 Online  
主題：職業技能特效第一版

## 今日目標

Day 15 已完成三職業技能資料與 server 端技能判定。  
Day 16 的目標是讓三個職業在按下 `J` 施放技能時，有明顯不同的視覺表現。

這一版先做 client 端視覺特效，不改 server 的傷害、距離、MP、冷卻規則。

## 完成內容

### 1. 普通攻擊與技能特效分離

原本普通攻擊和技能都是同一個矩形 hitbox 閃一下。  
現在保留普通攻擊的短距離黃色閃光，技能則依照職業分派到不同特效。

```text
K 普通攻擊：短距離黃色 hitbox
J 技能攻擊：依職業顯示不同技能特效
```

### 2. 劍士：斬擊

劍士技能改成近距離斬光：

```text
向前方出現藍白色斬擊光
帶有短暫位移與淡出
適合近戰職業的打擊感
```

### 3. 符咒師：靈符彈

符咒師技能改成飛出的符咒：

```text
從角色前方產生符紙
符紙向前飛行
帶有淡藍色尾跡與光暈
```

### 4. 獵人：遠射

獵人技能改成水平射擊線：

```text
前方產生細長射擊軌跡
帶有箭頭與亮色核心
速度較快，表現遠距離職業感
```

### 5. 技能命中衝擊

client 接上 server 回傳的 `combat:hit.skillId`。  
當技能命中怪物時，傷害數字旁會出現技能衝擊光圈。

目前用途：

```text
看得出技能真的命中怪物
多人時也能顯示其他玩家的技能命中效果
後續可擴充成不同技能命中動畫
```
