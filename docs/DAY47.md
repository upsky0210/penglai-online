# Day 47 踢出線上玩家（2026-06-26）

專案：蓬萊異聞錄 Online  
階段：課堂控場第二階段

## 今日目標

讓教師可以把單一線上玩家移出目前遊戲連線，處理測試卡住或課堂控場需求。

## 完成內容

### 1. 新增踢出 API

```text
POST /admin/kick?token=ADMIN_TOKEN
```

請求：

```json
{
  "playerId": "線上玩家 ID",
  "reason": "教師已將你移出遊戲，請稍後再重新進入。"
}
```

### 2. 玩家端處理

玩家會先收到教師公告式提示，接著 WebSocket 連線關閉。

### 3. 管理頁操作

線上玩家卡片新增：

```text
踢出
```
