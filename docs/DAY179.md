# Day 179 特效與 UI 素材規格
專案：蓬萊異聞錄 Online  
日期：2026-06-28

## 今日目標

- 定義招式、拾取、燈籠、霧氣與 UI 裝飾素材。
- 避免特效過大擋住主角與敵人。

## 特效規格

- 普攻斬擊：`64x32`，4 至 5 幀，透明背景。
- 靈斬：`96x48`，5 至 6 幀，偏青白與金色。
- 拾取閃光：`32x32`，4 幀，不遮住角色。
- 燈籠光暈：`96x96`，柔光圓形，可使用 additive 或低透明度。
- 霧氣：`256x96` 或 `512x128`，透明 PNG，可左右循環。

## UI 素材規格

- 面板邊框：9-slice 圖，建議 `64x64`，保留四角與邊框。
- 小圖示：`24x24` 或 `32x32`。
- 任務圖示：紅印、金邊、港町紙籤風格。
- 背包格：`40x40`，需有空格、選取、可用、不可用狀態。

## 限制

- 對話框、拾取提示、技能名稱不可蓋住主角太久。
- 戰鬥特效的可見時間建議小於 0.45 秒。
- UI 面板不可再次回到佔滿半個畫面的狀態。
