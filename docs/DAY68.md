# Day 68 任務導引跨地圖提示（2026-06-27）

專案：蓬萊異聞錄 Online  
主題：讓任務面板可以指引玩家前往另一張地圖。

## 完成內容

任務追蹤面板新增排序：

```text
可回報任務
進行中任務
可接任務
已完成任務
```

任務導引新增跨地圖判斷：

```text
目標 NPC 在別張地圖時，提示玩家往傳送門
目標怪物在別張地圖時，提示玩家往傳送門
同一張地圖時，仍顯示往左或往右距離
```

也修正 NPC 名稱查詢：

```text
從只查霧港試煉場
改成搜尋全部地圖 NPC
```
