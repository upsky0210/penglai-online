# 安平單機版改善報告與接續紀錄

日期：2026-11-09（臺灣時間）

## 本輪決策

先製作不依賴後端的安平單人探索樣板，驗證關卡分支、NPC 與歷史情境。Firebase 登入、雲端存檔及多人架構暫緩。遊戲預設入口已切換為新樣板；舊版透過 `?online=1` 進入，仍需啟動原有 server。

## 第一輪使用者試玩與修正

### 高架倉棧跳不上去

第一階原本接近跳躍極限，平台底部也會阻擋起跳。新增較低、較寬的木台，木架平台改成可由下方跳穿、由上方落地。保留原本跳躍高度，減少必須精準卡距離的情況。

### 潮位只看得到文字，突然被送回起點

通行規則為「退潮可走，漲潮時離開下方通道」。新增實際升降的藍色水面及波浪，週期為 36 秒：24 秒退潮、12 秒漲潮，漲潮前 4 秒預警。對話時潮汐暫停。水面與淹水判定共用同一高度，持續淹水 1.6 秒才救回岸上。

新增沿路自動檢查點；落水、體力耗盡與手動返回都會顯示原因及返回位置。返回後恢復體力並暫時保護角色，任務、藏物與金幣保留。

### 戰鬥缺乏血條與招式形狀

敵人增加名稱與隨血量縮減的血條。命中時顯示傷害數字，角色受傷有畫面提示。普通攻擊改為金色弧斬，技能改為較大的藍色弧形與扇面。友善 NPC 不作為攻擊目標，血條用於敵人。

### 移動稍快

水平移動從 235 px/s 調至 211.5 px/s，為原本的 0.9 倍；跳躍高度維持原值。

## 驗證結果

- `npm --workspace client run typecheck` 通過。
- `npm --workspace client run build` 通過；仍有既有大型 bundle 提示，尚未進行載入拆分。
- 本機無介面 Chrome 測試使用鍵盤事件，成功由地面登上高架木架並抵達上層平台，驗證水平速度為 211.5 px/s。
- 瀏覽器測試通過退潮通行、漲潮救援提示、平台碰撞、任務前置條件、工具修橋、家書回交、貨箱正確選項、守衛通關門檻與重載存檔；測試中無執行期例外。
- 流程測試部分透過場景方法觸發互動或設定狀態，並非完整依靠玩家操作的全程通關。臨時 Chrome 測試腳本與截圖放在被忽略的 `tmp/`，未納入此次交付。

## 回家後接續

在家中 checkout 執行：

```powershell
git pull --ff-only
npm.cmd ci
npm.cmd --workspace client run dev
```

開啟終端顯示的本機網址。網址埠號可能不同，不必固定使用目前這台電腦的 5175。不需要啟動 server。若電腦尚未有 repo，先 clone GitHub repo 再執行上述安裝及啟動指令。

**目前電腦的遊戲進度不會隨 Git 推送。** 存檔保存在瀏覽器，換電腦、瀏覽器或網站來源（包含不同埠號）會使用另一份進度。雲端同步與匯出／匯入尚未實作。

若要發布 Pages：到 GitHub 的 Settings → Pages，Source 選 GitHub Actions，再到 Actions 手動執行 `Deploy client to GitHub Pages`。推送本身不會發布網站。
