# P9-D 老師課堂功能

## 課堂進度總覽

教師後台的「線上學生進度」集中顯示角色名稱、等級、目前關卡、目前任務、進度、最後活動、本關停留時間及近 10 分鐘死亡次數。需關注學生排在前面，也可切換成只看需關注。

卡關警示是提醒老師觀察，不會改動學生資料。規則刻意保守：

- 5 分鐘沒有實際移動、互動或任務進度。
- 在同一關卡 10 分鐘，且進行中任務沒有進度。
- 10 分鐘內死亡至少 3 次。
- 前置任務未完成、停在後續 NPC 附近，且同時已 5 分鐘沒有活動。

伺服器只在既有玩家事件上更新記憶體時間戳。列表由教師手動重新整理時計算，不新增遊戲世界的高頻廣播；API 建議最快每 15 秒更新一次。

## 教師操作

- 全班提示：沿用公告廣播，選「課堂」分類。學生端以非阻塞提示顯示。
- 個別提示：在學生卡片輸入短提示後送出；只送給指定連線，不寫入公告資料表。
- 送回安全區：只把學生移到「目前關卡」的入口安全座標。保留地圖、任務、等級、經驗、HP／MP、金幣、背包、裝備與存檔，並立即存檔。
- 操作結果或錯誤會顯示在後台狀態列。成功的全班提示、個別提示與位置重置都寫入 action log。

位置重置不等同任務重置，也不跨關傳送。老師應先發提示；確認是地形或位置問題後再使用重置。

## 課堂成果 CSV

「下載課堂成果 CSV」包含角色名稱、職業、等級、關卡、完成任務數、任務總數、目前任務、狀態、進度與最後更新時間。刻意排除 email、save slot、密碼、token、session 與其他登入資料。

## 管理員 API

所有端點沿用 `ADMIN_TOKEN`：

```text
GET  /admin/classroom/progress
GET  /admin/classroom/progress.csv
POST /admin/classroom/hint
POST /admin/classroom/reset-position
```

個別操作 body：

```json
{ "playerId": "線上玩家 ID", "text": "提示內容" }
```

位置重置只需 `playerId`。不存在或已離線的玩家回傳 `404 player_not_online`；空提示回傳 `400 empty_hint`；未授權回傳 `403`。
